# JueguitosLabs

Un pequeño laboratorio de juegos, acertijos y herramientas para quienes disfrutan jugando con las palabras, la lógica y los números.

## ¿Qué es?

JueguitosLabs nace como una colección de experiencias sencillas que se pueden abrir y utilizar directamente desde el navegador. La idea es añadir poco a poco juegos y utilidades, con especial atención a una experiencia accesible y agradable.

## Disponible ahora

### Laboratorio de anagramas

Permite introducir letras, reorganizarlas con el ratón o el teclado, mezclarlas y probar combinaciones sin que una herramienta revele automáticamente la solución.

## Ideas para el futuro

- Juegos de palabras: Colmena, palabras ocultas y crucigramas.
- Juegos de lógica: sudoku, nonogramas y deducción.
- Utilidades para resolver acertijos: patrones, cifrados y anagramas.
- Retos diarios, estadísticas y creación de retos compartibles.

## Tecnología

**Primera etapa:** HTML, CSS y JavaScript sin dependencias, publicados con GitHub Pages.

**Evolución prevista:** incorporar una aplicación Laravel y un ecosistema de servicios cuando las necesidades del producto lo justifiquen. Por ahora se prioriza la simplicidad y la posibilidad de jugar sin crear una cuenta.
